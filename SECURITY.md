# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a vulnerability

If you find a security vulnerability in Jager-C2 (teamserver auth bypass, implant crash, key leakage, etc.), please report it responsibly:

1. Open a **private** security advisory via GitHub ("Security" tab -> "Report a vulnerability"), or
2. Email the maintainers if you prefer not to use GitHub.

Please include reproduction steps and affected versions. Do not open a public issue for exploitable vulnerabilities.

We aim to acknowledge reports within 72 hours and will work with you on a coordinated disclosure timeline.

## Scope

In scope: the teamserver, MCP server, builder, CLI, and implants in this repository.

Out of scope: engagement infrastructure you or others deploy, the actions of users running the tool, and reports that require a malicious operator to attack their own teamserver.

## Acceptable use

Jager-C2 is provided for authorized security testing and research only. See the MIT LICENSE and the disclaimer in the README. Reports of abuse should go to the maintainers via the same channels.
